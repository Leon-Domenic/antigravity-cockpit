# Tailwind CSS & UI Design System

## Overview
Best practices for modern utility-first CSS styling and layout structuring.

## Key Rules
1. Use semantic CSS variables for themeable backgrounds, borders, and text.
2. Build responsive layouts mobile-first (sm:, md:, lg:, xl:).
3. Ensure high contrast and accessible focus states (ocus-visible:ring-2).
